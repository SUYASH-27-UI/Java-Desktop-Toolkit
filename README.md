# Java Desktop Toolkit 🚀
A collection of daily standalone Java Swing desktop applications.

Topics: java, swing, gui-applications, desktop-apps, oop, java-projects, productivity-tools

| Day | Project Name | Description & Tech Stack |
|:---:|:---|:---|
| **01** | **Digital Clock** | Real-time updating desktop clock app. (`JFrame`, `Timer`, `SimpleDateFormat`) |
| **02** | **Simple Calculator** | Desktop GUI calculator for basic arithmetic. (`JFrame`, `GridLayout`, Action listeners) |
| **03** | **To-Do List Manager** | Desktop productivity task tracking app. (`DefaultListModel`, `JList`, Event handling) |
| **04** | **BMI Calculator** | Fitness utility to calculate Body Mass Index. (`JTextField`, Math logic, Status formatting) |
| **05** | **Password Generator** | Desktop security tool to generate random passwords. (`Random`, Checkboxes, String building) |
| **06** | **Stopwatch Timer** | Desktop timer utility with start, stop, and reset features. (`JFrame`, `Timer`, State logic) |
| **07** | **Temperature Converter** | Desktop utility app to convert temperature values across units. (`JFrame`, `JComboBox`, Math formulas) |
| **08** | **Bill Splitter** | Financial desktop app to calculate tips and split bills among multiple people. (`JFrame`, Financial math) |
| **09** | **EMI Calculator** | Desktop financial tool to calculate loan EMIs and total interest. (`JFrame`, Financial math) |
| **10** | **Pomodoro Timer** | Desktop productivity timer for focus work and breaks. (`JFrame`, `Timer`, Time logic) |
| **11** | **Word Counter** | Desktop text analysis utility to track words, characters, and metrics. (`JFrame`, `KeyAdapter`, String parsing) |
| **12** | **Dice Roller** | Desktop random number generator and dice rolling utility. (`JFrame`, `Random`, Dropdown selection) |
| **13** | **RGB to Hex Converter** | Developer utility tool to convert RGB color codes to Hex with live preview. (`JFrame`, `Color`, Formatting) |
| **14** | **Quick Notepad** | Desktop mini text editor with file save and open operations. (`JFrame`, `JFileChooser`, File I/O) |
| **15** | **Unit Converter** | Desktop utility app to convert lengths across multiple units. (`JFrame`, `JComboBox`, Scaling math) |
| **16** | **BMI Calculator** | Fitness desktop utility to calculate Body Mass Index and health status. (`JFrame`, Math logic) |
| **17** | **Quote Generator** | Desktop GUI app that displays random inspirational tech quotes. (`JFrame`, `Random`, UI card layout) |
| **18** | **Countdown Timer** | Desktop event tracking timer app. (`JFrame`, `Timer`, Time logic) |
